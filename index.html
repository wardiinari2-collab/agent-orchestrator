Agent Task Orchestrator

Run multi-step tasks from YAML with plugin system, Telegram bot, and cron scheduling.

View on GitHub Get Started

Features

Multi-Step Tasks

Define complex workflows in YAML. Steps execute sequentially with context passing between them.

Plugin System

Extend with custom plugins. Auto-discover from directory. Built-in HTTP, text, and file plugins.

Telegram Bot

Control orchestrator from Telegram. Run tasks, check status, view history — all from chat.

Cron Scheduler

Schedule recurring tasks with standard cron expressions. Background execution with logging.

Quick Example

# tasks/check_url.yaml
name: check-url
steps:
  - name: fetch
    handler: http.get
    params:
      url: "https://api.example.com/health"
  - name: verify
    handler: text.contains
    params:
      text: "$step_fetch"
      keyword: "ok"

Install

pip install agent-orchestrator
agent-orch run tasks/check_url.yaml

Architecture

agent-orchestrator/
├── src/agent_orchestrator/
│   ├── engine.py          # Core orchestrator
│   ├── plugin.py          # Plugin system
│   ├── scheduler.py       # Cron scheduler
│   ├── telegram_bot.py    # Telegram interface
│   └── task.py            # Task/result types
├── plugins/               # Auto-discovered plugins
├── tasks/                 # Task definitions
└── config.yaml            # Configuration
